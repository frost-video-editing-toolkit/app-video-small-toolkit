# Integration tests

このフォルダには、FFmpegとGoワーカーを実際に起動する統合テストを置きます。

## テストの配置

- `worker/main_test.go`: Goワーカー内部の単体テスト。`worker`パッケージの非公開関数を直接検証するため、`worker`フォルダに置きます。
- `test/integrationt-test.js`: FFmpegとGoワーカーを実際に起動する統合テスト。このフォルダに置きます。

`worker/main_test.go`をこのフォルダへ移すと、Goのパッケージ境界を越えて非公開関数を参照できなくなり、`go test ./...`で実行できません。

## 回帰テストとは

回帰テスト（regression test）は、以前動いていた機能が新しい変更によって壊れていないことを確認するテストです。

例えばこのプロジェクトでは、次のような不具合が再発していないことを確認します。

- 同名動画の出力先が上書きされない
- FFmpeg完了イベントに出力ファイルが含まれる
- crop、cut、loopが実際に動画を生成できる
- 無音ログの解析結果が正しい

## 前提

- Node.js
- Go 1.23以上
- PATHから`ffmpeg`を実行できること

## 実行

リポジトリのルートで実行します。

```text
npm run test:integration
```

テストは一時フォルダに短い動画を生成し、cropジョブをGoワーカーへ渡します。確認対象は次の3点です。

- ワーカーが成功結果をJSONで返す
- 完了イベントに出力ファイルが含まれる
- 出力ファイルが実際に生成される

生成した動画はテスト終了時に削除されます。
